# Temelie.Repository.UnitTests

NUnit tests for [Temelie.Repository](https://github.com/michaelpaulus/temelie/blob/main/src/Temelie.Repository/README.md) and the source generators. They run against an in-memory SQLite database using the AdventureWorks sample entities and repository.

```shell
dotnet test src/Temelie.Repository.UnitTests
```
