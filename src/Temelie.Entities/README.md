# Temelie.Entities

Base types and attributes for Temelie entities. Entities are usually generated by [Temelie.Entities.SourceGenerator](https://github.com/michaelpaulus/temelie/blob/main/src/Temelie.Entities.SourceGenerator/README.md) and used through [Temelie.Repository](https://github.com/michaelpaulus/temelie/blob/main/src/Temelie.Repository/README.md).

```shell
dotnet add package Temelie.Entities
```

| Type | Purpose |
| --- | --- |
| `EntityBase` | Abstract base record for all entities. |
| `IEntity<T>` | Marks `T` as an entity (`T : EntityBase`). Repositories and generators use it to discover entities. |
| `ICreatedDateEntity`, `ICreatedByEntity`, `IModifiedDateEntity`, `IModifiedByEntity` | Audit columns. The repository fills them in automatically on add and update. |
| `[HasTrigger]` | The table has triggers; EF Core is configured accordingly. |
| `[ColumnPrecision(precision, scale)]` | Decimal precision and scale for the EF Core model. |

Standard `System.ComponentModel.DataAnnotations` attributes (`[Table]`, `[Key]`, `[Column]`, `[DatabaseGenerated]`, `[MaxLength]`) describe the rest of the mapping.

An entity, as the generator emits it:

```csharp
[Table("Address", Schema = "Person")]
public partial record Address : EntityBase, IAddress
{
    [Key]
    [DatabaseGenerated(DatabaseGeneratedOption.Identity)]
    [Column("AddressID", Order = 1)]
    public virtual int AddressId { get; set; }

    [MaxLength(60)]
    [Column("AddressLine2", Order = 3)]
    public virtual string? AddressLine2 { get; set; }
}
```
